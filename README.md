# 連接車のパラメトリック生成

`launch.py` をBlenderの外のPythonで実行すると設定ウィンドウが開きます。数値を変えると約160msの入力待ちの後、Rev.Bと同じ配色・構成の寸法図を再描画します。図は直線の長手方向配置で、幅・高さは模式表示です。

このPCでは `起動.cmd` のダブルクリックでも起動できます。動作確認済みの3種類のモデル・画像・試験結果は `サンプル/` にあります。

## 起動

```text
python launch.py
```

Python 3.10以降、tkinter、Pillowが必要です。このPCでは、通常のPythonにPillowがない場合、既存のCodex同梱Pythonを自動利用します。追加のインストールや既存環境の変更はしません。他のPCでは `python -m pip install -r requirements.txt` でPillowを導入してください。

BlenderはPATH、標準インストール先、Steam版の配置から検出します。見つからなければ「Blender参照」でblender.exeを指定します。このPCのBlender 5.2.2で生成確認済みです。

## 操作

1. 上部で3種類のプリセットを選びます。
2. 各車体長、車体間隔、通常台車の位置などを入力します。複数の値はカンマ区切りです。
3. 右側の寸法図が更新されます。上部で詳細表示する車両を選択できます。拡大表示時はスクロールできます。
4. 「3D生成・画像出力」、または「3D生成＋接触試験＋画像出力」を押します。Blenderはバックグラウンドで起動します。
5. 保存先が画面に表示されます。出力の `編成_指定条件.blend` を開けば3Dモデルを確認できます。

処理中も設定は編集できますが、実行中の条件は開始時点のままです。編集後の設定と結果が違う場合は「変更前の条件」と表示します。処理が終わるまではアプリを閉じられません。

## 入力値と自動計算

- 車体長は各車体の端面間。全車とも断面はVer2.0で固定、車端絞りはありません。
- 車体間隔は直線状態の隣り合う車体端面間です。曲線では隙間の見え方が変わります。
- 共有台車位置比率は左車体の右端から隙間に沿って測ります。0.5で隙間中央です。
- 通常台車の距離は、編成外側の車体端から内側への距離を左右別に指定します。
- 台車中心間、編成全長、車体の位置は自動計算します。編成全長を固定する制約モードはありません。
- 両端通常台車を無効にした場合、編成外端の台車は最寄り連接部と対応する外側張出しで配置します。外端の参考連結器は作りません。
- 設定車体数は2～20両。間隔と共有位置比率の個数は車体数−1です。通常台車の内側距離・連結器突出は左右2個です。
- 半径0は直線。曲線はR100以上、カント0、動揺0です。建築限界断面の補間は既存Ver2.0の100/Rです。
- 機器限界は入力した試験半径と配置半径の最小値に合わせて端部を切り詰めます。幅3mを確保できない間隔はエラーにします。
- パンタグラフ仮形状は各車体中央、長さ2m、幅1.3m、レール上4.29～4.515mで固定です。

## 保存内容

`出力/日時_編成名/` に保存します。実行ごとに新しいフォルダなので前回出力を上書きしません。

- `設定.json`：再実行可能な入力値。
- `部品モデル.blend`：各部品を固有原点に配置。部品は重なるため、必要なものを個別表示してください。
- `編成_直線.blend`、`編成_指定条件.blend`：配置済みの車体・車両限界・機器・参考連結器。
- 通常台車付きでは、編成同士と20m級との接続シーンも直線・指定半径で保存。
- `寸法確認図.png`：Rev.B形式の編成図・選択車詳細・寸法整理。生成時は先頭車を詳細表示します。
- `モデルプレビュー.png`、`機器配置限界.png`、`連接部_上面.png`、`連接部_斜視.png`：既存と同系統の配色・背景の3D画像。
- `検証結果プレビュー.png`：既存と同じ3カード形式で連接部1を示します。
- `検証結果.json`、`試験結果.md`：接触試験を選んだ場合の結果。
- `実行ログ.txt`：Blenderのログ。`完了.json`：Blender処理完了記録。

建築限界は元の20.5m直線プリズム・シェイプキーを維持しています。編成に追従した曲線トンネルではありません。配置シーンでは初期非表示です。曲線への適合は解析計算で確認します。

## 試験

既定は直線とR100/125/150/200/300/500/1000/2000の左右曲線です。設定した配置半径も試験に追加します。

- 車体・車両限界・固定パンタグラフ・機器・参考連結器の建築限界への水平余裕。
- 全車体同士、全車両限界同士、各車体／限界と機器、機器同士の平面分離。
- メッシュが閉じていること、正体積、ゼロ面積面がないこと。
- 各試験配置でメッシュ表面交差を確認。判定では平面輪郭の重なりも使うため、完全包含を表面検査だけで見落としません。
- 通常台車付き編成は、同じ編成との連結および20m級との連結を追加。20m級は台車中心間14～15mを0.01m刻みで走査し、各半径・方向・対象の最悪条件でメッシュ交差を確認します。
- 参考連結器同士の接合や車体への取付部の重なりは、車体・機器の接触判定対象から除きます。連結器のリンク距離は検査します。

車体接触、車両限界の重なり、建築限界逸脱は別々に記録します。41m＋20m級では、既存どおりR100で車両限界が約36.24mm重なりますが、車体は約218.71mm分離します。

分離余裕は平面の分離軸上の隙間下限であり、3D最短距離ではありません。建築限界は既存と同じ断面折点・区間20分割での照合です。緩和曲線、S字、勾配変化、動揺、実機の旋回制約は対象外です。

旧15mモデルの車体端間隙間は共有台車の接線軸への投影値です。この値も `adjacent_tangent_gaps` に保存し、3カード画像の車体・車両限界欄に使います。SATの分離余裕とは評価軸が違うため、値はわずかに異なります。

## 画面なしで実行

```text
python launch.py --all
python launch.py --config プリセット/連接車_41m_通常台車.json
python launch.py --config 設定.json --no-test --no-render
python -m unittest test_geometry.py
```

## ファイル構成

| ファイル | 役割 |
|---|---|
| launch.py | 外部Pythonからの起動・一括実行 |
| gui.py | 入力画面・即時プレビュー・実行状態 |
| configuration.py | 設定・プリセット・入力検証 |
| geometry.py | 共通寸法・配置・平面輪郭 |
| drawing.py | 寸法図・試験カード画像 |
| verification.py | 建築限界・平面接触試験 |
| runner.py | Blender起動・出力管理 |
| blender_worker.py | Blender内の実行入口 |
| blender_model.py | 3D部品・配置・メッシュ試験・保存 |
| rendering.py | 3Dプレビュー画像 |
| data/ | Ver2.0の基準コピーと断面座標 |

既存フォルダのファイルは変更しません。実行に必要な基準データはこのフォルダ内のコピーを読みます。
